## 清洁使用与卸载

持久写入位置及正常 Certbot 写入见 [README](../README.md#写入范围与卸载)。

- 在真实生产安装上分别执行 `status` 和 `uninstall --detach --dry-run`。
  对程序目录、配置目录、状态目录、命令链接、续期配置和 Certbot 锁文件做前后快照，
  文件内容、权限和修改时间均未变化，没有新建或删除文件。
- 生产卸载预览正确识别两个登记的程序环境和五个配置文件。
  它们包括本次接入及升级留下的备份，实际卸载会一并处理。
- 在临时目录中完成真实安装，再让已安装的 Python 执行自身卸载；
  程序目录和命令链接被移除，未留下临时 Certbot 锁。
- 修改后的配置、仍在使用的 hooks、待清理挑战、未知状态文件和状态目录符号链接等拒绝路径有自动化测试。
  用户额外文件保留；证书、私钥和 Certbot 自己的数据不作为工具垃圾删除。
- 校验失败的升级测试确认旧程序仍可运行，当前版本链接未切换。

生产环境只执行了卸载预览，保留安装以继续自动续签。
